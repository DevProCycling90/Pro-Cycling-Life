# 🚴 Pro Cycling Life

> **Écris la carrière d'un coureur cycliste, de 16 ans jusqu'à la retraite.**

**Pro Cycling Life** est un jeu de carrière cycliste jouable dans le navigateur, inspiré des jeux de management et de carrière sportive.

Tu incarnes un jeune coureur et construis progressivement sa carrière : formation, premiers résultats, passage professionnel, progression, rivalités, transferts, sponsors, réputation, choix tactiques et grandes décisions de carrière.

L'objectif n'est pas simplement de gagner des courses.

**L'objectif est de construire une carrière.**

---

## 🎮 Le concept

Dans Pro Cycling Life, chaque coureur possède sa propre identité.

Tu dois gérer :

* 🚴 ta spécialité et ton style de course ;
* 🌳 ton arbre de compétences ;
* ⚡ ta fatigue et ton surmenage ;
* 🧠 ta motivation et ton moral ;
* 🤝 tes relations avec les autres coureurs ;
* ⚔️ tes rivalités ;
* 👥 tes équipiers ;
* 👔 ton équipe et ton directeur sportif ;
* 💰 tes contrats et tes sponsors ;
* 📰 ton image médiatique ;
* ❤️ ta popularité auprès des fans ;
* 🏆 ton palmarès ;
* 🌍 ta réputation dans le peloton ;
* 📖 l'histoire de ta carrière.

Les décisions prises à 16 ans peuvent influencer la carrière du coureur plusieurs années plus tard.

---

# 🧑‍🎓 Une carrière qui commence à 16 ans

La carrière ne commence pas directement chez les professionnels.

Le joueur traverse d'abord une période de formation durant laquelle il doit faire des choix concernant :

* son entraînement ;
* ses études ;
* ses premières compétitions ;
* son comportement ;
* ses relations ;
* sa récupération ;
* son image ;
* ses premières opportunités.

Ces choix peuvent influencer son développement et les opportunités professionnelles qui lui seront proposées à 18 ans.

L'objectif est que le premier contrat professionnel soit la conséquence de ce qui s'est passé pendant les premières années de carrière.

---

# 🌳 Un arbre de compétences pour construire son coureur

Le Skill Tree permet de personnaliser progressivement le coureur.

Les compétences permettent notamment d'améliorer :

* les performances sportives ;
* certaines spécialités ;
* la récupération ;
* la gestion de carrière ;
* les relations ;
* les médias ;
* les sponsors ;
* la réputation ;
* les choix narratifs.

Certaines compétences ne donnent pas simplement un bonus numérique : elles peuvent débloquer de nouvelles situations ou modifier les conséquences de certains événements.

Le joueur doit donc choisir entre plusieurs philosophies de carrière.

**Quel type de coureur veux-tu devenir ?**

---

# 🚴 Un Race Engine basé sur les décisions

Les courses sont structurées comme des séquences de décisions.

Selon la situation, le joueur peut notamment choisir de :

* attaquer ;
* suivre ;
* collaborer ;
* économiser ses forces ;
* prendre des risques ;
* protéger un équipier ;
* jouer son propre résultat.

Les décisions consomment de l'énergie et peuvent influencer directement la situation de course.

Le résultat dépend donc du coureur, mais également du contexte, de son état physique et des décisions prises pendant la course.

---

# 📅 Une carrière construite autour du calendrier

Le calendrier propose différents profils de courses :

* classiques ;
* courses vallonnées ;
* courses de montagne ;
* épreuves de sprint ;
* contre-la-montre ;
* courses à étapes ;
* grands tours.

Le choix du calendrier est une véritable décision stratégique.

Participer à trop de courses peut augmenter la fatigue et compromettre les objectifs futurs.

À l'inverse, bien construire son programme permet de préparer certains objectifs importants.

---

# ⚡ Fatigue, récupération et surmenage

La gestion physique est une composante importante de la carrière.

Le joueur doit gérer :

* la fatigue immédiate ;
* la récupération ;
* la forme ;
* le surmenage ;
* la charge de compétition ;
* les risques liés à une carrière trop intensive.

Un calendrier trop chargé peut permettre d'accumuler les résultats à court terme tout en compromettant les performances futures.

---

# 🤝 Relations & rivalités

Les autres coureurs ne sont pas uniquement des adversaires statistiques.

Le jeu mémorise les interactions et permet de construire progressivement :

* rivalités ;
* respect ;
* tensions ;
* alliances ;
* relations avec les équipiers ;
* historiques de confrontation.

Une rivalité peut évoluer au fil des saisons et être réutilisée dans les événements de carrière.

---

# 👥 Un peloton vivant

Le joueur évolue dans un monde composé de nombreux coureurs avec leurs propres :

* nationalités ;
* spécialités ;
* personnalités ;
* potentiels ;
* niveaux ;
* équipes ;
* carrières.

Le peloton évolue également avec le temps.

Les coureurs vieillissent, changent d'équipe, progressent et prennent leur retraite.

De nouvelles générations apparaissent pour renouveler progressivement le monde.

---

# 👔 Équipes, DS et contrats

La carrière ne dépend pas uniquement des performances.

Le joueur doit également gérer sa relation avec :

* son équipe ;
* son directeur sportif ;
* ses équipiers ;
* ses sponsors.

Les choix de carrière peuvent opposer plusieurs trajectoires :

> rester équipier dans une grande structure
> **ou**
> devenir leader dans une équipe moins prestigieuse.

Le mercato devient ainsi une décision de carrière et pas seulement une recherche du meilleur contrat.

---

# 💰 Sponsors & objectifs

Les sponsors font partie intégrante de la carrière.

Les performances et la réputation peuvent influencer :

* les opportunités ;
* les revenus ;
* les objectifs ;
* les primes ;
* les contrats.

Le joueur doit donc trouver un équilibre entre ambitions sportives, attentes de l'équipe et exigences commerciales.

---

# 🌍 Quatre réputations différentes

La réputation est divisée en quatre dimensions :

| Réputation      | Ce qu'elle représente                         |
| --------------- | --------------------------------------------- |
| 👥 **Peloton**  | Respect et perception par les autres coureurs |
| ❤️ **Fans**     | Popularité auprès du public                   |
| 📰 **Médias**   | Image et visibilité médiatique                |
| 💰 **Sponsors** | Attractivité commerciale                      |

Ces réputations ne sont pas uniquement décoratives.

La réputation dans le peloton peut par exemple influencer la coopération des autres coureurs pendant une course : une bonne réputation facilite les alliances, tandis qu'une mauvaise réputation peut rendre les collaborations plus difficiles.

Certaines compétences permettent également de modifier les conséquences des événements liés à l'image et à la réputation.

---

# 🧠 Une carrière qui garde une mémoire

Le jeu conserve un historique des événements importants de la carrière.

Les événements marquants peuvent inclure :

* victoires ;
* défaites ;
* rivalités ;
* changements d'équipe ;
* compétences importantes ;
* choix de carrière ;
* événements narratifs ;
* performances remarquables.

L'objectif est de permettre à la carrière de construire progressivement sa propre histoire.

---

# 🏆 L'objectif : construire sa propre légende

Il n'existe pas une seule manière de réussir.

Un joueur peut chercher à devenir :

* 🏆 un grand champion ;
* ⛰️ un spécialiste des grands tours ;
* ⚡ un sprinteur dominant ;
* 🧱 un spécialiste des classiques ;
* 🤝 un équipier fidèle ;
* 🌟 une star populaire ;
* 📰 une personnalité médiatique ;
* 💰 un coureur recherché par les sponsors ;
* 🧠 un spécialiste reconnu dans son domaine.

La réussite d'une carrière ne dépend donc pas uniquement du nombre de victoires.

---

# 🔁 Rejouabilité

Chaque carrière commence avec un coureur différent et peut suivre une trajectoire différente.

Les choix effectués pendant les premières années peuvent influencer :

* le développement ;
* les compétences ;
* les relations ;
* les rivalités ;
* les contrats ;
* les équipes ;
* la réputation ;
* les opportunités ;
* le palmarès.

L'objectif est de pouvoir recommencer une carrière et découvrir une histoire différente.

# 🚀 Lancer le projet

## Installation

Clone le dépôt :

```bash
git clone https://github.com/USERNAME/pro-cycling-life.git
cd pro-cycling-life
```

Installe les dépendances :

```bash
npm install
```

Lance le serveur de développement :

```bash
npm run dev
```

Puis ouvre l'adresse indiquée par le terminal dans ton navigateur.

# 🎯 Philosophie du projet

Pro Cycling Life cherche à répondre à une question simple :

> **Et si on pouvait vivre toute la carrière d'un coureur cycliste comme une histoire interactive ?**

Le jeu ne cherche pas à reproduire chaque détail du cyclisme professionnel.

Il cherche plutôt à créer un système dans lequel :

**les performances créent des opportunités,
les choix créent des conséquences,
les relations créent des histoires,
et les histoires construisent une carrière.**
